# Mots-clés des postes (LRB S3 + Dungeon Bowl Edition 2022)

> Source : `_lrb_raw.txt` (§12 LRB Saison 3) et `_dungeonbowl_raw.txt` (§ Collèges DB).
> Format : `Poste → Mots-clés (CSV)`
>
> **Convention de lecture** : dans le LRB, chaque ligne de stats est suivie d'une ligne indentée
> donnant les mots-clés sous la forme `[Type de poste] [Race(s)] [Autre]`.
> Pour le Dungeon Bowl, les mots-clés sont déduits du nom de poste et du rôle (roleNom), en
> l'absence de ligne de mots-clés explicite dans le fichier condensé.
>
> `⚠️` = mots-clés non explicites dans le PDF, déduits par convention.
