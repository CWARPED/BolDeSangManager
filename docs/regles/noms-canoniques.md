# Noms canoniques des postes (correction)

> Source : PDF LRB S3 (`_lrb_raw.txt`, MAJ 11/04/26) et Dungeon Bowl (`_dungeonbowl_raw.txt`, MAJ 27/10/24).
> Convention PDF : la ligne d'entrée de roster `0–N  [NOM]  coût stats…` donne le nom canonique.
> La ligne en retrait dessous (`     Trois-quart Humain`, `     Blitzer Elfe`, etc.) est le **type/rôle+mots-clés** — jamais part du nom.
> Seuls les postes dont le nom doit changer sont listés. Les noms déjà canoniques sont omis.

## Dungeon Bowl

> Le fichier `_dungeonbowl_raw.txt` liste les postes sans parenthèses : la colonne POSTE contient uniquement le nom du joueur (e.g. `Skink Runner`, `Norse`, `Eagle Warrior`, `Human`, etc.). Les noms du seed DB ajoutent des suffixes de collège entre parenthèses (`(Cieux)`, `(Feu)`, etc.) pour éviter les collisions de noms entre collèges — ce suffixe n'est **pas** dans le PDF.
>
> Règle de correction : supprimer les parenthèses de collège quand le nom de poste est unique dans tout le DB. Quand le même nom générique (`Orc`, `Human`, `Skaven`, etc.) apparaît dans plusieurs collèges, le suffixe est nécessaire comme discriminant.

## Récapitulatif des règles de correction

1. **Parenthèses de rôle BB** : supprimer `(Trois-quart)`, `(Blitzer)`, `(Lanceuse)`, `(Bloqueuse)`, `(Bloqueur)`, `(Lanceur)`, etc.
2. **Préfixe `Gros Bras`** : à supprimer du nom quand le PDF liste le nom propre sans ce préfixe (ex. `Ogre Renégat` pas `Gros Bras Ogre Renégat`). Exception : conserver quand le nom générique seul serait ambigu (`Gros Bras Homme-arbre`, `Gros Bras Ogre` dans des équipes avec un seul Gros Bras de ce type).
3. **Suffixes de collège DB** `(Cieux)`, `(Feu)`, `(Ombre)`, etc. : à supprimer. Les collisions de noms entre collèges n'ont pas lieu dans l'UI (chaque équipe DB est un `TeamType` distinct).
4. **Suffixes de rôle DB** `Lineman`, `Runner`, `Blitzer`, `Thrower`, `Blocker` : à conserver quand le même nom de race générique (`Dark Elf`, `Orc`, `Human`, `Vampire`, etc.) est utilisé pour plusieurs postes du même collège.
